# Feature List

 - [x] Orientable camera with real-time first-person controls
 - [x] Multisample antialiasing
 - [x] Ray-sphere intersections
 - [x] Ray-triangle intersections
 - [x] Ray-quadrilateral intersections
 - [x] Ray-cuboid intersection
 - [x] Ray-quadric intersections
 - [x] Loadable textures (non-bitmap formats provided by stb-image)
 - [x] Textured geometry
 - [x] Loadable triangle meshes with texturing via Wavefront OBJ and MTL formats
 - [x] Object primitive instancing
 - [x] BVH spatial subdivision acceleration 
 - [x] Specular, diffuse, dielectric, and colloidal (homogeneous volumetric) materials
 - [x] Emissive surfaces
 - [x] High dynamic range rendering
 - [x] BRDF materials with Cook–Torrance (GGX D, Smith masking-and-shadowing G, Schlick F)
 - [x] Object and camera motion blur
 - [x] Phyiscally based depth-of-field
 - [x] Perlin noise and checkerboard procedurally generated textures
 - [x] Cube-mapped skybox
 - [x] Importance sampling (next-event estimation for direct lighting and shaped reflection lobes)
 - [x] Aggressive parallelization
 - [x] Vertex normal interpolation for smooth shading
 - [x] Post-process lens diffraction modelling with aperture mask via FFT and convolution
 - [x] Spatio-temporal sample reprojection
